# Next GM UI Review Checklist

## Vibe

- Does it feel like a premium wrestling broadcast command center?
- Does it avoid generic SaaS/admin UI?
- Does it feel like a console sports-management game?

## Layout

- Does the screen fit viewport-first?
- Is scrolling limited to contained panels?
- Is there one clear primary workspace?
- Are secondary panels visually quieter?
- Is the next action obvious?

## Visual system

- Is red used as signal, not wallpaper?
- Is gold reserved for prestige/money/titles/rank?
- Is green used for healthy/ready/positive states?
- Are warning states yellow/orange?
- Are panel tiers visually distinct?

## Information architecture

- What is selected?
- What is urgent?
- What changed?
- What can the player do?
- What are the consequences?

## Production value

- Are there real asset slots for portraits, belts, brands, badges, show art?
- Are icons SVG/component-based, not emoji?
- Do titles/championships feel prestigious?
- Does the screen avoid empty black boxes?

## Quality

- Any clipped text?
- Any text outside containers?
- Any unreadable labels?
- Any over-dense rows?
- Any inconsistent spacing?
- Any full-page scroll introduced?
- Any CSS one-offs that should be reusable tokens/components?
