# Next GM UI Anti-Patterns

## Hard no

- Generic SaaS dashboard.
- Rounded bubbly cards.
- Overly soft gradients.
- Pure red across the whole screen.
- Full-page scrolling on main game screens.
- Emoji icons.
- Placeholder art treated as final.
- Unclamped text overflow.
- Clipped panel content.
- Empty panels with one stat.
- Equal visual weight everywhere.
- Mobile card-stack layout as the desktop game UI.
- Admin-form rhythm for creative/gameplay actions.

## Looks cheap because

- Red is used as wallpaper instead of signal.
- Panels have borders but no hierarchy.
- Text is all the same size/weight.
- Everything is italic/skewed.
- Data has no consequence.
- The player cannot tell what to do next.
- There are no portraits, belts, badges, or show assets.
- The UI is dense but not organized.
- It looks like HTML styled to be edgy, not a shipped console screen.

## Fixing principles

- Darken first, then add selective light.
- Add frame hierarchy before adding glow.
- Add assets before adding more CSS effects.
- Use gold only where prestige/money/title value matters.
- Use red only where heat/focus/danger matters.
- Make the selected object obvious.
- Put consequences next to actions.
- Make the primary action visually dominant.
