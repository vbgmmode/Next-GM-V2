# Codex Prompt Templates

These are copy/paste prompt templates for Codex work on Next GM. They are meant to keep each request focused, bounded, and aligned with `AGENTS.md`.

## Recommended workflow

1. Use `repo-report.md` when unsure what changed or what exists.
2. Use `new-feature-ticket.md` for one bounded gameplay/UI feature.
3. Use `bugfix-ticket.md` for one broken behavior.
4. Use `refactor-ticket.md` only when behavior should not change.
5. Use `verify-current-build.md` after risky changes.
6. Use `post-feature-report.md` after Codex implements a ticket.
7. Use `update-agents.md` after every 2-3 completed feature slices or whenever the project phase changes.

## Usage rules

- Paste one prompt at a time.
- Keep every ticket bounded.
- Acceptance tests are the stopping point.
- Do not ask Codex to build multiple major systems in one prompt.
